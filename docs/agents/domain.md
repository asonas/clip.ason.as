# Domain Docs

このリポジトリは single-context 構成を使用する。

## 探索前に読むもの

- ルートの GLOSSARY.md
- docs/adr/ のうち、対象領域に関係する ADR

存在しなければそのまま作業を進める。
未作成であることを問題として扱わず、事前の作成も提案しない。
用語や判断が固まった時点で domain-modeling スキルが作成する。

## 用語

Issue、設計案、仮説、テスト名には GLOSSARY.md の用語を使う。
定義に反する同義語へ置き換えない。
必要な概念が未定義なら、既存用語で表せるか確認し、
実際に不足していれば domain-modeling の検討事項とする。

## 設計判断

提案が既存 ADR と矛盾する場合は、対象 ADR と再検討の理由を明示する。
黙って上書きしない。
